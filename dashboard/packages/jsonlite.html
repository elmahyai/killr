All 22 exports are done. JSON tokens, base64, and gzip use the Python standard library. Data frames are row objects, length-one list values stay arrays, and a missing data-frame cell is omitted. The compiled code is C, including yajl, so there is no crate. rbind_pages covers the column-union case; vctrs is suggested, not imported.
