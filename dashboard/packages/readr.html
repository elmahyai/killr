readr

CRAN 2.2.0

Edition 2 reads and writes delimited text in Python. Types are guessed the way vroom guesses them, so whole numbers are doubles. Time zones use zoneinfo. read_rds and write_rds use digest's version-2 serializer. read_builtin loads a named dataset from a package lazy-load database. Compression code 3 is raw LZMA2 with a 5-byte header.
