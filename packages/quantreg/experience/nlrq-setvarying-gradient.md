After `m$setVarying()` and a later `m$setPars()`, R's `m$gradient()` is no longer a matrix. For a vector-valued right-hand side, `getRHS.varying` evaluates `attr(ans, "gradient")[useParams]`, a linear index that recycles the logical mask over the n-by-p gradient, so the result is a plain vector of length n. The gradient is not the varying columns. Probed with a 10-row fit: dim NULL, length 10. The translation leaves `setVarying` out rather than copy this.
