R's `cumsum` adds in long double and rounds each running total to double. `numpy.cumsum` adds in double. A knot built as `cumsum(c(x[1], diff(x)))` can then differ by one ulp, and a stepfun value at that exact knot flips. In `rearrange`, the knot 3.1 came out as 3.0999999999999996 in numpy and 3.1 in R, so the value at 3.1 moved from 2.5 to 3.3. Accumulate in `np.longdouble` and cast back to double.
