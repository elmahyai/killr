Parameter ulps become gradient noise. numericDeriv divides a rounding error of about one ulp of the fit by a step near 1e-8, so a 1e-12 parameter difference from R moves the gradient by about 1e-8. summary.nlrq then moves its bootstrap standard errors by about 5e-9 and its t values by about 3e-8. At R's exact parameters the Python summary matches to 2e-14, so the gap is the nlrq optimizer path, not the summary. numpy exp also differs from the C library exp by one ulp on some inputs, so nlrq evaluates exp through libm.
