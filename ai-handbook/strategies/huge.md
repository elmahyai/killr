# Strategy: huge

More than 200 exports. The package stays on the Huge card and is not in progress.

The stand-in check is `strategies/orchestrator.md`. The task force waits until that check says there is no stand-in.

The batch is one task force: functions in this package that are relevant to each other, finished together. It is not one function, and it is not the rest of the package. A task force does not finish the package, and it is not a check of the whole R package. The model is the first match in `strategies/orchestrator.md`.

Add only the Python or Rust library this package needs beyond what is already agreed.

If Fortran or C that computes turns up, the package stays `huge`. The kernel is still a crate. The task force does not translate it.
