`diag(x)` with one numeric value is an identity matrix of size `as.integer(x)`, not a 1-by-1 matrix holding `x`. `diag(2.7)` is a 2-by-2 identity and `diag(0.3)` is 0-by-0. The same happens for a length-one vector, so a one-dimensional `diag(rep(sigmasq, p))` or `diag(scale * shape)` inside mclust `meEII` or `meEEI` does not give `sigmasq` on the diagonal. NumPy `np.diag` of one value gives a 1-by-1 matrix, so the Python side must use a helper that returns `np.eye(int(x))` for length one, as `r_diag` in `packages/mclust/mclust/_me_e_family.py` does.
