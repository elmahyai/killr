`invalid` treats missing, empty, and failed calls as true before it walks lists. `even` and `odd` must mark `NA` from `%%`, because NumPy `nan == 0` is false. `logit` of a negative is R's positive NaN. `inv.logit(+Inf)` is 1. `foldchange2logratio` is `log(x, base)` after the sign split. `ddirichlet` uses `all.equal` for the simplex, not raw float equality. `baseOf` errors on `NA_integer_` before the inner function. `binsearch` flips the comparison with `sign` so a decreasing function still moves. `capwords` treats `sep` as a regex. `na.replace` evaluates a function replacement on the whole vector. `running` center alignment has length `n + width - 1`. `chr` of one zero byte is `""`, not `"\0"`. `split_path` uses R `dirname`, not `os.path`. `permutations` with repeats tiles the inner matrix. `combinations` follows the recursive `rbind` / `cbind`, not a lexicographic iterator.
