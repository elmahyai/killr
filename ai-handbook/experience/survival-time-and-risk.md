Cholesky is stored column-first: `matrix[col][row]` is the R element, and `cholesky2` writes the lower triangle into the upper. Two-column `Surv` stores time in column 0; R `y[, ny - 1]` with `ny == 2` is that column, so NumPy uses `y[:, ny - 2]`. `basehaz` must read `fit$y` after `coxph` has recoded status to 0 and 1.
`survSplit` censors `status[index + 1]`, not `status[index]`. `survcondense` start times use 1-based `cumsum(lengths)`. `tmerge` still indexes `yinc[pmax(1, index)]` when `index` is 0. `finegray` `findInterval` is 1-based, and a zero index is dropped. `concordance` ranks are `match` of unique sorted risks, not `searchsorted`. `royston` uses average ranks when `eta` has no ties. `pyears` output is already in column order. `pyears3b` must increment the cut index with a C-style `for`. `clogit` method `exact` is `coxexact`, not `coxfit6`. `cch` waits on `coxfit6`, `agfit4`, and the score kernels. `nsk` needs exact `splineDesign` derivatives, not a finite difference. `cipoisson` brackets `qgamma` and bisects when Wilson-Hilferty leaves the bracket. `dsurvreg` Gaussian uses `math.erfc`. `psurvreg` and `qsurvreg` Student-t use SciPy. `strata` crosses labels, not rows. `is.ratetable` reads `names(dimnames)`. `lvcf` walks `order(id, time)`. `survobrien` `all.vars` drops `factor` and `I`. `survfit0` checks `x$xtd.err`, which never exists, so the time-zero `std.err` is always 0, and a multi-state `pstate` row is filled with `rep(p0, each=curves)` in column-major order. `survConcordance.fit` counting data sorts stop times by `order(-stop, status)`, and a censored row in `Cconcordance2` is added with `i < j`, not `i <= j`. Both kernels now come from the `survconc` crate, imported by `surv_concordance` from `survConcordance_fit`, so the old Python loops are gone. Before that death is scored, rows whose start is `>=` the death time are removed from the tree. The `dsurvreg` Student-t CDF helper `_pt` is off by about 3e-4 in the tails, so `survreg.distributions` density takes SciPy `t.cdf`. `yates_setup` dispatches on the fit class. Its coxph `survival` branch builds the default curve the way `survfit.coxph` does, through `coxsurv_fit` with `se.fit` and `conf.type` log, then drops rows with no events (`censor = FALSE`). It needs the fit's stored `x` (`x = TRUE`), and `rmean` defaults to the largest death time. `survdiff2` writes the Kaplan–Meier weight before the deaths at that time, and `strata` is 1 on the last row of each stratum. A risk set of one skips the variance update. `agexact` centers a column only when `nocenter` is nonzero; a zero flag stores a zero mean. Tied deaths sum every `doloop` combination of the risk set `start < stop`. In `agmart`, `deaths` is a double, so `k/deaths` is floating division, and method 0 makes the hazard and the Efron hazard the same. `coxfit6` keeps the information in the lower triangle (`imat[j][i]` for `j <= i`, flat index `i*nvar+j`). The symmetrizing loop copies that triangle upward (`imat[j*nvar+i] = imat[i*nvar+j]`). `chinv2` inverts a Cholesky factor, so the convergence path and the `maxiter == 0` path call `cholesky2` on `imat` before `chinv2`. `survreg6` returns the `cholesky3` rank in `flag`, and 1000 when the Newton loop stops short. `survregc1` fills the triangle `cholesky3` reads, `matrix[col][row]` with row <= col, so that fit does not copy the other triangle the way `cholesky2` does. `survreg.fit` picks the kernel from the list's `name`, so only "Extreme value", "Logistic", and "Gaussian" reach the crate. Called directly, `weibull` and `loglogistic` have other names and need the R callback (dnum 4), and `t` does too even through `survreg()`, which only swaps in the base list for aliases. `survfitcoxph.fit` ignores `vartype`. survtype 2 is Breslow (`coxsurv.fit` ctype 1, stype 2) and survtype 3 is Efron (ctype 2, stype 2); `newrisk` and `id` are passed on as `risk2` and `id2`. `survfitKM` reads weighted risk, events, and censors from columns 4–6 of the `survfitkm` matrix `n`; columns 1–3 are the unweighted counts, returned in `counts` only when the weights are not all 1, and column 8 is the weighted entry count. The Aalen-Johansen kernel reads time1, time2, and state; a two-column competing-risks response gets a dummy start of 0 when min(time) > 0, otherwise 2*min(time)-1, and status is remapped onto the survcheck state list with the initial state first. `hindx[from + nstate*to]` is the 0-based transition. `survpenal` adds the penalty's second derivative to the diagonal of `hmat` and `JJ` with column stride `nvar + nstrat`, not `nvar`; with a stride of `nvar` the x2 penalty landed at the intercept-x2 entry, and the coefficients still converged while the variance was off by about 1e-3.
