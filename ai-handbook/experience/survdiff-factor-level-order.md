`survdiff` group and stratum codes follow R's sorted factor levels, not first-appearance order. `strata()` ranks each row's tuple of level codes with the first variable most significant, so the groups are the sorted tuples. `survdiff.py` builds these codes itself. `strata.py` `_as_factor` ranks character values by first appearance, which orders groups differently from R's `factor()`, so a character `strata()` call there does not match R's group order. R's `pchisq(0, 0, lower.tail = FALSE)` is 1, so a single present group gives chisq 0 and pvalue 1.
