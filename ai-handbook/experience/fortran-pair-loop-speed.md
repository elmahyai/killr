A Fortran `do i; do j = 1,i-1; if (adjchk(i,j))` loop tests every pair, which is quadratic. In a Rust port of deldir `delseg` and `dirseg`, that loop cost about 350 ms of a 3000-point `master`. Walking each point's neighbour list instead, with j kept in ascending order and `1 <= j < i`, gave about 35 ms with the same output. The proof matched R exactly. Keep the emit order (i ascending, then j ascending), and keep the adjacency check on the neighbour pairs. The check that a non-neighbour pair is not listed on the other side is lost, so this is only valid when the lists are symmetric by construction.
