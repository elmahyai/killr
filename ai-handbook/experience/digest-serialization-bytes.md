Empty AES-CTR still runs `for (i in 1:0)`, so the IV advances twice. `rawToChar` drops a trailing nul. `charToRaw` of a longer vector warns and keeps the first string. `hash` of bytes sign-extends each `char`. A repeated symbol in version 2 is the four-byte reference `255 | (index << 8)`. Attributes of a vector are written after the values; a pairlist writes them before the CAR. Ascii serialization uses C `%.16g`. `hmac` compares `algo` before `match.arg`, so `"sha5"` hashes as sha512. Lazy-load compression code 3 type `Z` is raw LZMA2, not gzip.
