An item whose Rd has `\docType{data}` and whose name is not in `R/` is a data set with no function to call, so it is reported and not ported. Data sets are often bundled in one `.rda`, so names may not match a file: in survival 3.8-12, `cracks`, `genfan`, and `ifluid` are in `data/reliability.rda`, and `gbsg` and `hoel` are in `data/cancer.rda`. List each `.rda` with `load()` to find the object before the batch is opened. In survival 3.8-12, aml and the bladder sets have no file in data/ and are not exported in NAMESPACE, and braking is only an alias in man/reliability.Rd.
