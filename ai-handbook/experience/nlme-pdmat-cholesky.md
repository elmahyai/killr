`pdMat` with a square matrix stores `np.linalg.cholesky`, which is lower triangular, but R's `chol()` is upper. The `pdSymm` path then takes the SVD of the wrong factor, so a 3x3 `pdMat(m, pdClass="pdSymm")` gives 0.72173 where R's `pdSymm(m)` gives 0.66141. A 2x2 matrix hides the bug, and the `pdDiag` proof never reaches it. Use `U = L.T` before any SVD or `crossprod`, as `nlme/pdsymm.py` and `nlme/pdnatural.py` do. Column-major upper-triangle order is `[(r, c) for c in range(n) for r in range(c + 1)]`.
