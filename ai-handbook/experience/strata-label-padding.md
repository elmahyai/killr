R's `strata()` with named arguments pads the labels of the second and later variables. Each `name=level` label for variable `i >= 2` is run through `format()`, so it is padded to the widest label of that variable. `strata(group, site)` therefore gives `group=A, site=east ` with a trailing space, while the first variable is never padded. `strata.py` `_format_labels` does not pad, so a two-variable `strata()` label there does not match R. `survfit_formula` builds its own labels with the padding. A single `strata(x)` term in a survfit formula is labelled `strata(x)=level` with the plain level, not `x=level`.
