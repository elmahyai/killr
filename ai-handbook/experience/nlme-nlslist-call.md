`nlme.nlsList` rebuilds the `nlme` call from the call stored on the `nlsList` object. The Python `NlsList` now keeps the formula and the data for that, so the method needs the fit and not the original call. The fixed start is the median of the group estimates. R's random start is `(madRan / madRes)^2` on the diagonal, and `random_start_matrix` computes it, but `nlme_formula` does not read it yet. Loblolly with `random = Asym ~ 1` still matches R to about 2e-13. R's default `random = fixed` gives three random effects, and the Python fit takes one random intercept only, so that default is not translated. `SSasympOff` is the self-start the `nlme` path needs; its gradient columns are in the order `(Asym, lrc, c0)`.

The no-start path is R's `plinear` initial fit, which stops at R's convergence test and does not reach the optimum. Its numerical derivative step rounds an iterate by one ulp into a 1e-8 relative error in the gradient, so the result matches R only when every step is bit-for-bit: `nlme/linpack_qr.py` replays R's `dqrdc2`/`dqrsl` through `libblas.so.3` (the same OpenBLAS R loads), uses R's long-double `sum` and `mean`, and calls `math.exp`/`math.log` for glibc rounding. With that, no-start and with-start match R exactly (`proof/nlsList-nostart-compare.py`).
