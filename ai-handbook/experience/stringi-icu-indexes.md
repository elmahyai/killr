stringi 1.8.9 is ICU 76. Python 3.13 Unicode tables are older, so new characters need an `Rscript` check. `stri_sub` and `stri_sub_all` treat `from = 0` with `length` differently. `stri_join` keeps missing values missing. NFKC casefold is applied one character at a time, then NFC. Fixed search must not expand a code point whose uppercase is longer than one character. UnicodeSet and BreakIterator indexes are UTF-16. Calendar times in PyICU are seconds, not milliseconds. Collation strength must use `setAttribute`, because `setStrength` clamps an illegal value. `RegexMatcher.find()` without a start index swallows timeout errors; `find(start)` raises them.
