`rowLogSumExps` calls `logSumExp_double` and must not reuse the vector index resolver: a positive index past the end is allowed on the vector and is an error on the row. An NA margin index is `-Inf` when `na.rm` is TRUE.
Check the installed C, not only the manual. `weightedMean` keeps a negative weight. `weightedMedian` drops weights `<= 0`, but a `+Inf` weight keeps only infinite weights and then counts `-Inf`. `rowWeightedMeans` errors on a non-missing negative weight and does not call `weightedMean`.
`rowRanges` stops a row only on R's NA payload. Integer `rowDiffs` wrap. `rowMad` with an omitted center wraps the mean of two integers when their difference is even; `colMads` subtracts in double. A missing row median is `NA_real_`; an empty one is plain NaN. `rowVars` uses the C path only when `center` is NULL, and `sqrt` must keep NA's bits. `rowQuantiles` type 7 does not clamp `probs`; other types floor `nppm * (1 + fuzz)`.
`rowCollapse` treats `idxs` as a vector subscript and `rows` / `cols` as matrix subscripts. `rowOrderStats` is `rPsort`, and `which` is `asInteger(which) - 1`. `diff2` truncates `differences`, but `varDiff` divides by `2^diff` using the original value. A null weight in `weightedVar` is built before `idxs` and is not subset until `na.rm`. `rowAvgsPerColSet` clears the column index before subsetting `W`. `allocMatrix` tests `nrow < 0` twice, so a negative `ncol` is "negative extents".
