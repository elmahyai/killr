Shifts copy the kept edge and fill the other. `shift.left` errors when `ncol == 1` and `cols >= 1`. `shift.down` fills with float so a non-integer fill is not truncated. `lower.triangle` zeroes `row < col`; `upper.triangle` zeroes `row > col`.
`matrix.power` is an identity at 0, repeated `@` when positive, and inverse plus recursion when negative. Do not call `numpy.linalg.matrix_power`. `matrix.inverse` is `solve` on a square float matrix. `svd.inverse` is thin `V diag(1/d) t(U)` with an exact zero on `d`. Default `matrix.rank` is LINPACK `qr` rank, not `np.linalg.qr`; `method="chol"` is `dpstrf`.
Zero eigenvalues below `tol` before a sign test. Definite tests fail on `<= 0` or `>= 0`. Semi-definite tests fail only on a strict wrong sign. Indefinite is true only when both strict signs remain.
`frobenius.norm` and `hilbert.schmidt.norm` are `entrywise.norm(x, 2)`. `frobenius.prod` is `sum(hadamard.prod)`. A vector `y` is shaped with `nrow = length(x)`. Infinite `p` calls `maximum.norm` on the original `x`, which errors on a vector because of R's `Xmat` typo. Empty `one.norm` and `inf.norm` are `-Inf`. `direct.prod` is Kronecker after a vector becomes a column. `direct.sum` is block diagonal.
`lu.decomposition` uses 1-based `im1 <- i - 1`; in a 0-based loop that is `im1 = i`. Stop on an exact zero pivot. `set.submatrix` assigns at 1-based indexes. `hilbert.matrix` is `1 / outer(0:(n-1), 1:n, "+")`. Toeplitz needs length `2n-1`. Hankel circular-shifts a vector of length `m >= n`. `stirling.matrix` is `(n+1)` square, and `n == 1` hits R's early return. `pascal.matrix` returns the LU factor `L` of the symmetric Pascal matrix. `K.matrix` sums `kron(Hij, t(Hij))`. `N.matrix` is `(K + I) / 2`. A one-line R wrapper stays a one-line Python wrapper.
`is.square.matrix` is only dimensions, and `0×0` is square. Symmetry is exact `x == t(x)`, not a tolerance. `is.diagonal.matrix` zeroes the diagonal then `all(abs(y) < tol)`. `matrix.trace` sums from 0, so `sum(-0)` is `+0`, and an integer sum stays integer through 2147483647.
