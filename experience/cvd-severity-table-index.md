Machado CVD lists hold eleven 3 by 3 matrices named 0 through 10. `interpolate_cvd_transform` clamps severity to that range. Below 0 it returns the first matrix, and at 1 or above it returns the last. Otherwise it blends `floor(10 * severity)` and `ceiling(10 * severity)`. An exact tenth returns that named matrix and does not blend. R stores the list 1-based, so the matrix named k is element k + 1.
