RColorBrewer `display.brewer.pal` uses `image(1:n, 1, as.matrix(1:n))`, so `par("usr")` is `0.5`, `n + 0.5`, `0.6`, and `1.4`.
`hex2RGB` keeps seven characters and divides by 255. Coercing sRGB to RGB applies `ftrans` per channel; HSV and HLS from sRGB use those gamma channels directly, not a polar roundtrip. Gamma 2.4 uses the cutoff 0.03928, not `convertColor`'s 0.04045. `darken` is `lighten` with a negated amount. Combined `lighten` copies chroma from linear RGB via polar LUV, not from sRGB. `max_chroma` bilinearly interpolates the table at `h + 1e-8` and `l + 1e-8`. `diverging_hcl` must leave arguments missing so a named palette is not overwritten. `LUV` does not call `CheckMatrix`; `LAB`, `XYZ`, and `RGB` do. `sRGB` returns space `"sRGB"`. Integer colors index the current eight-color `palette()`, which starts `black`, `#DF536B`. `mixcolor` HSV and HLS use the C hexcone tables.
