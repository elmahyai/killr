A crate `#[pyfunction]` declared with one `args: Bound<PyTuple>` parameter, and no `#[pyo3(signature)]`, takes one positional tuple. Calling it with the Fortran arguments spread out raises `TypeError: ... takes 1 positional arguments but 14 were given`. Pass them as one tuple, for example `kernel((x, z, n, ...))`. `mclust_kernels` in `crates/mclust/src/python.rs` is built this way; its installed signature shows `(args)`.
