`trace()` and `untrace()` print their function name to stdout (`[1] "Initialize.reStruct"`) even when they are called at top level in a proof script. A proof that reads the last JSON line from `Rscript` stdout then fails to parse. Wrap both calls in `invisible(...)`, or read only the lines that start with `{`. The `nlme` recalc proof captures `conLin` through `trace()`, so it hit this on the first run.
