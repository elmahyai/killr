`tapply` with no function returns 1-based group codes. Bootstrap indexes fill down columns. `round` scales the fractional part alone, so some exact ties differ from NumPy. Probability sampling breaks ties with a 1-based heapsort, and Walker's alias table is used only when more than 200 weights satisfy `n * p > 0.1`. `glm.diag` leverages use the weights from the iteration that met the deviance test. `saddle` keeps the last Nelder-Mead vertex. `saddle.distn` on the city alpha 0.001 quantile misses 1e-8 because the spline is rank-deficient; that miss stays recorded. `lm(y ~ x + x^2)` is `lm(y ~ x)`.
