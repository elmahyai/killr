`bcrypt_pbkdf` is OpenBSD C in `crates/bcryptpbkdf`, not opensslport. `fingerprint` needs leading-zero bignum padding from `openssh.c` in `crates/opensshfp`; Ed25519 is the raw 32-byte key. `ec_dh` is DER Diffie-Hellman in `crates/ecdhdh`; X25519 stays on opensslport. `read_p12` loads the legacy provider before `Pkcs12::parse2` and uses `OPENSSL_sk_*` on OpenSSL 3. Ed25519 sign and verify are one-shot; `EVP_DigestSignUpdate` is unsupported. `rsa_sign` uses uppercase `MD5`, `SHA1`, and `SHA256` nids.
`write_pem` turns a raw seed into DER before `write_key`. `read_pubkey` routes PEM in Python and OpenSSH wire format in `readpubkey`. A single-line path is a file when `os.path.isfile` says so.
