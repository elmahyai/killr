`Names<-` on a `pdMat` first tries each new name as given. When any unmatched name is longer than 12 characters, unmatched names ending in `.(Intercept)` lose that suffix before the match; the other unmatched names get `.(Intercept)` appended. The stored Dimnames keep the caller's spelling, so `Names(pd)` returns `day.(Intercept)`. A permutation of an initialized object needs `pdConstruct`, which is not translated yet.
