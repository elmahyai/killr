clmm's default start is clm.fit's coefficients. The nlminb path has no gradient, so finite differences amplify rounding: a one-ulp change in the start moves the optimum by about 1e-7 in the coefficients and the Hessian by about 1e-5. Given R's exact start, the Python objective matches R bit for bit (wine, judge, nAGQ 1 and 10). Matching the default path to 1e-8 needs a bit-exact clm.fit start, so check the start first with a fixed-start comparison.
