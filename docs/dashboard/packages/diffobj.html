diffobj 0.3.9 is translated. Styles load crayon. The formatted diffs use the myersmba port of src/diff.c. Rdiff_chr and Rdiff_obj call the tools.rdiff useDiff path, which is clean() plus diff -bw. guides and trims follow the R methods: a list of strings is a character vector.
