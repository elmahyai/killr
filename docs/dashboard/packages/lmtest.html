All 23 exports of lmtest 0.9-40 are checked on a linear model. The Durbin-Watson probability is Farebrother's pan in the Rust crate. F, chi-square, and t tails use SciPy. The Cox normal tail uses extraDistr's math.erf. Granger lags use zoo's lag and merge. Harrison-McCabe draws use extraDistr's normal generator on boot's Mersenne-Twister. glm, mlm, and survreg methods are not in the exports that were checked.
