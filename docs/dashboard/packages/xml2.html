xml2

CRAN 1.6.0

All 67 function exports are done. The four classes are the node types those functions return. Documents, XPath, schema checks, and URLs call the system libxml2 through ctypes, the library the installed package links. download_xml uses urllib. cli and rlang are not opened: their calls here are error text and one boolean. curl is suggested, and a curl handle is unused. There is no Fortran, so there is no crate.
