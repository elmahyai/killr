All 101 records match R at 1e-8. The atomic and list windows, including the segment-tree summaries, run in the `slider` Rust crate (src/segment-tree.c, summary-slide.c, summary-index.c) through `slider_kernels`, with the NumPy fallback kept for an install without the wheel. Period windows and block() use warp. The data-frame binders are Polars frames: vec_rbind and vec_cbind are reimplemented in `slider/bind.py`. Polars keeps column names unique, so a result R would repeat a name in raises instead; that is the one shape the binders cannot reproduce.
