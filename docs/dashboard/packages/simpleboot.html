CRAN simpleboot 1.1-8 is translated. one.boot, two.boot, and pairs_boot call the translated boot(). The linear-model bootstrap matches. loess.boot matches loess(surface='direct'); the default interpolated surface still differs, and that check is recorded with matches false.
