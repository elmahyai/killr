All exports of mvtnorm 1.4-2 match R within 1e-8. Genz–Bretz and TVPACK are the Fortran in crates/mvtdst, with uniforms from boot and univariate margins from SciPy. Miwa is the C orthant routine in that crate. Lower-triangular algebra and the log-likelihoods are NumPy. utils::getFromNamespace is only used to call this package's own invchol, so utils is not loaded.
