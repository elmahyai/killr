Kill CRAN.

R holds some of the best statistics code in the world, and it is trapped in R. killr is an agent system that translates the CRAN catalog into Python and Rust, and proves every translated function against the original R output.

How it works

One pipeline, from R to Python and Rust

An orchestrator hands each package to translation agents. Each agent follows a written constitution and a plan sized to the package. Nothing counts as done until it matches R.

O

Orchestrator

Orders packages by dependencies and download rank, and caps how many run at once.

C

Constitution

One set of rules: the order of work, the routing to stand-ins, the proof, and the Rust kernel rule.

S

Strategies

Small, medium, large, and huge packages each get a plan that fits. Compiled code gets a -low variant.

E

Experience

Every pitfall becomes a lesson that later agents read before they start, so it is made once.

The full flow with the graph is in the strategy document.

What is next

Still early, and getting better

The agents are fast, but a first translation is not the last word. The work ahead is review, coverage, and quality.

More review rounds open

Every complete package gets another review pass, so the first translation is not the final one.

  • Review the 133 complete packages again
  • Resolve the 7 proof checks that do not match yet
  • Finish the 14 packages in progress

Raise Rust coverage open

More of the compiled numerics move into Rust, so they run without a C or Fortran toolchain.

  • Turn more Fortran and C kernels into crates
  • Show Rust coverage on the dashboard

Decisions still open open

Some choices need agreement before the work can go on.

  • Which big libraries stand in for R frameworks
  • Whether the 38 replaced packages need a second look

The full list is in the roadmap.
