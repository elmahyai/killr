Proof of concept · An agent system for R to Python and Rust

killr

R has the best statistics packages in the world, and they are trapped in R. killr is an agent system that translates the CRAN catalog into Python and Rust, and proves every translated function against the original R output.

The problem

Statistics runs on R, but production runs on Python and Rust. Porting by hand is slow, and every port drifts from the original.

01

Locked in R

Core algorithms live in R and C and Fortran code that most teams cannot maintain or ship in their own stack.

02

Slow to port

Thousands of functions across hundreds of packages. A manual port takes years and is never finished.

03

Silent drift

A port that looks right can still give different numbers. Without a check against R, nobody knows.

The approach

An orchestrator hands each package to translation agents. Each agent works under a written constitution and a strategy that matches the package size. Every function must match R before it counts as done.

Orchestrator

Decides what runs

Picks the next package by dependencies and download rank, and caps how many run at once.

Constitution

Sets the law

One document of rules: the order, the routing to stand-ins, the proof, and the Rust kernel rule.

Strategies

Fits the size

Small, medium, large, and huge packages each get their own plan. Packages with compiled code get a -low variant.

Experience

Learns from mistakes

Each pitfall an agent hits becomes a lesson that later agents read before they start.

The full flow, with a graph, is in the strategy document.

What is next

This is a proof of concept. The agents are fast, not finished. The work ahead is review, coverage, and quality.

More review rounds open

Every translated package gets another review pass, so the first translation is not the last word.

  • Review the 133 complete packages again
  • Check the 7 proof checks that do not match yet
  • Finish the 14 packages in progress

Raise Rust coverage open

More of the compiled code moves into Rust, so the heavy numerics run without a C or Fortran toolchain.

  • Turn more Fortran and C kernels into crates
  • Measure Rust coverage on the dashboard

Decisions still open open

Some choices need agreement before the work can go on.

  • Which big libraries stand in for R frameworks
  • Which of the 38 replaced packages need a second look
